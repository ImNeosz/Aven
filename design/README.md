# Aven visual identity

`aven-brand-concept.png` is the original concept sheet supplied for Aven's visual direction.

The production icon derived from it lives at `resources/aven-app-icon.png`, with the Windows multi-resolution version at `resources/aven.ico`. Use the dark rounded-square icon as the default. Keep the large wordmark and tagline out of routine browser surfaces; Aven's chrome should remain quiet and content-first.
